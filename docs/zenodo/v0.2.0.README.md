All twelve theorems across the three projects discharged sorry-free in
sixteen minutes of wall-clock time using Harmonic AI's Aristotle prover.
Each was verified to depend only on standard mathematical axioms
(`propext`, `Classical.choice`, `Quot.sound`). No theorem signature was
weakened; the one cosmetic change (Lean 4 keyword-escape `protected` →
`«protected»` in T-VG-03) was disclosed by the prover and structurally
verified semantic-preserving.
