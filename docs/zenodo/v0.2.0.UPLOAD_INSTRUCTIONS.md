## Step-by-step upload (assuming v0.1.0 already published)

1. Navigate to the existing v0.1.0 record's Zenodo page.
2. Click **New version** in the right sidebar.
3. **Files**: replace the v0.1.0 archive with `verdigraph-neurogenesis-v0.2.0.zip`
   (generated by zipping the unpacked folder; instructions below).
4. **Version**: change to `0.2.0`.
5. **Publication date**: `2026-05-26`.
6. **Description**: replace with the `description` field from `.zenodo.json`.
7. **Keywords**: replace with the `keywords` array from `.zenodo.json` (note
   new keywords: formal verification, Lean theorem prover, mathlib, Aristotle).
8. **Creators**: add Aristotle (Harmonic) as second creator OR as a contributor.
9. **Related identifiers**: confirm the arXiv:2510.01346 citation is present.
10. **Notes**: replace with the `notes` field from `.zenodo.json`.
11. **Reserve DOI** for the new version (versioned DOIs differ from concept DOI).
12. Save draft, review thoroughly (immutable once published), then publish.

## Generating the upload archive

From the repository root:

```bash
cd zenodo_deposit
zip -r verdigraph-neurogenesis-v0.2.0.zip verdigraph-neurogenesis-v0.2.0
tar -czf verdigraph-neurogenesis-v0.2.0.tar.gz verdigraph-neurogenesis-v0.2.0
```
